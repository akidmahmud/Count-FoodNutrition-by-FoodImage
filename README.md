# Food Nutrition Analysis App

This application analyzes food images to provide nutritional information including:
- Macronutrients (carbs, protein, fat)
- Micronutrients (vitamins, minerals)
- Dietary improvement suggestions

## Features
- Upload food images
- Get detailed nutritional analysis
- View suggestions for dietary improvements
- Historical record keeping

## Setup
1. Clone the repository
2. Install requirements: `pip install -r requirements.txt`
3. Set up your OpenAI API key
4. Run the app: `streamlit run app.py`

## Environment Variables
- OPENAI_API_KEY: Your OpenAI API key

Check out the configuration reference at https://huggingface.co/docs/hub/spaces-config-reference
